# Обход DPI для Rematch (Epic Online Services)

Минимальный self-contained набор: один `.bat` с обходом, один `.bat` для
остановки, и нужные бинарники рядом от оригинального [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)

## ВАЖНО

Этот форк был сделан ТОЛЬКО ДЛЯ КОННЕКТА К СЕРВЕРАМ REMATCH.
Он не помогает с youtube, discord и так далее - только REMATCH(возможно и другие онлайн игры).

## Быстрый старт

1. Запустить `Rematch.bat`.
2. Запустить и играть REMATCH.
3. После игры запустить `Rematch-stop.bat` - чинит зависший драйвер без
   перезагрузки компьютера.(эта проблема у многих на оригинальном запрете тоже)

Не держите два экземпляра `winws.exe` одновременно (например, службу zapret и
этот батник): двойной перехват роняет сеть.


## Как это работает

Проблема, под которую собран форк: матч-сервер принимает первые пакеты
рукопожатия и через полсекунды перестаёт отвечать - поиск матча проходит,
загрузка висит 60 секунд и возвращает в меню. При этом HTTPS к Epic работает
без всякого обхода.(с оригинальным zapret даже при установленном game filter только на UDP выдает ошибку коннекта к epic games services при запуске игры)

Приём заимствован из форка
[reateroff/zapret-game-udp-fix](https://github.com/reateroff/zapret-game-udp-fix)
и состоит из трёх частей:

- **`--dpi-desync-ttl=4`** - поддельный пакет живёт только до ТСПУ и умирает по
  дороге. Сервер его не получает, поэтому не рвёт соединение. Без этого пункта
  обход ломает и вход, и матч.
- **`--dpi-desync-fake-unknown-udp=bin\stun.bin`** - размер подделки 100 байт.
  Типовые `quic_initial_*.bin` и `ACTIVE_GAME_UDP.bin` весят 1200 байт, и по
  такому размеру ТСПУ распознаёт фейк.
- **`--dpi-desync-cutoff=n4`** - десинк только на первых четырёх пакетах
  соединения, дальше трафик идёт как есть и не платит задержкой.

## Параметры

Всё управление - одна строка в `Rematch.bat`:

```
--dpi-desync-ttl=4
```

Если матч не коннектится, поставьте `3`, потом `5`. Значение зависит от того,
на каком хопе стоит ТСПУ у вашего провайдера. Узнать свой:

```
tracert <IP сервера матча>
```

Первый хоп, где вместо адресов только `* * *`, и есть нужный TTL. IP сервера
матча видно в логе игры:
`%LOCALAPPDATA%\Runtime\Saved\Logs\Runtime.log`, строка
`UPendingNetGame::SendInitialJoin ... RemoteAddr: <IP>:<порт>`.
